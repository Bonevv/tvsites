# ТВ Сайтове

Android приложение с начален екран и раздели ТВ, Видеотека, Радио, Сайтове и Настройки. Всички раздели използват обща графитено-лилава тема с бял фокус и ляво меню. Програмата на телевизията се отваря с OK в плеъра. Всички съществуващи сайтове остават достъпни за ръчно ползване; радиото предлага и директни потоци.

От канал до лявото меню се стига веднага с ←, Назад или Menu; → връща на същия канал. В лентата ↑ ↓ избира раздел, а OK го отваря. Горе се виждат приблизителната RAM на процеса и свободната RAM на устройството.

[Свали последната версия](https://github.com/Bonevv/tvsites/releases/latest)

Качване на код в GitHub стартира съществуващото автоматично компилиране и публикува APK в Releases. За локално компилиране са нужни JDK 17, Gradle 8.9 и Android SDK 34:

```bash
gradle :app:assembleRelease
```
