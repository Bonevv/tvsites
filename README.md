# ТВ Сайтове

Android приложение с раздели ТВ, Видеотека, Радио, Сайтове и Настройки. Програмата на телевизията се отваря с OK в плеъра. Всички съществуващи сайтове остават достъпни за ръчно ползване; радиото предлага и директни потоци.

[Свали последната версия](https://github.com/Bonevv/tvsites/releases/latest)

Качване на код в GitHub стартира съществуващото автоматично компилиране и публикува APK в Releases. За локално компилиране са нужни JDK 17, Gradle 8.9 и Android SDK 34:

```bash
gradle :app:assembleRelease
```
